## 1. Computer Networking — OSI Model Overview

Today, I explored the Open Systems Interconnection (OSI) model, a conceptual framework that describes network communication through seven layers.

### The Seven Layers

| Layer | Name | Main Responsibility |
|---|---|---|
| 7 | Application | Provides network services to applications |
| 6 | Presentation | Deals with data representation, encryption, and compression |
| 5 | Session | Describes how communication sessions are managed |
| 4 | Transport | Handles end-to-end data transport |
| 3 | Network | Handles logical addressing and routing |
| 2 | Data Link | Handles communication between devices on the same local link |
| 1 | Physical | Transmits raw bits through a physical medium |

### Some Familiar Protocols and Technologies

- **Application:** HTTP, HTTPS, DNS, SMTP, SSH
- **Transport:** TCP and UDP
- **Network:** IP and ICMP
- **Data Link:** Ethernet and Wi-Fi
- **Physical:** Copper cables, fiber optics, and radio signals

These are simplified examples. In real networking, some protocols and technologies don't fit perfectly into just one OSI layer.

### Other Concepts I Explored

- Why the OSI model is useful for understanding network communication.
- The basic responsibilities of each layer.
- The difference between the OSI model and the TCP/IP model.
- The basic idea of encapsulation and decapsulation.
- An introductory understanding of network devices such as hubs, switches, and routers.
